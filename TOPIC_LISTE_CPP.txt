Pointeur_2
Ici il y a Deux types de variables.
1. elle contient des valeur de type quelconque
2. elle contient des adresse de mémoire 
exemple 
int nombre = 206 => c'est une variable
int * p_nombre  => c'est l'entier que contient l'adresse de la  mémoire
int * p_nombre = 0 => c'est l'initialisation de la case de mémoire en affectant la valeur 0 à l'intérieur
ou une autre façon d'écrire int* p_nombre(0)
p_nombre = &nombre => c'est affectation de l'adresse de mémoire dans la variable p_nombre - la valeur  de cette variable est une adresse de mémoire

Pointeur_4
Dans la manipulation de la mémoire, il est possible d'imposer l'adresse de mémoire pour une valeur donnée. Pour ce faire il faut allouer une mémoire, mais avant d'allouer ce mémoire il faut initialiser avec une valeur, car une case de mémoire vide est impossible. 
Voici la procédure
int * p_valeur = 0;
p_valeur = new int; ici on impose que ce mémoire là qui contiendra la valeur.
*p_valeur correspond donc à la valeur qui contiendra cette case de mémoire. 
L'avantage est de pouvoir vider ce mémoire en faisant delete p_valeur à la fin du programme.

Enum_1
On peut créer une liste d'objet du même type mais sous une forme très simplifié. Enum .
C'est une class dont le nombre d'objets instancié est limité et restreint et prédéfini.
Par exemple je veux créer une liste de spécification de pipes. Dans cette liste on peut trouver les nom de spec.
enum spec {P8104, P8105, P3600};
